# I’m building a WiFi survey tool for Meta Quest 3

I’m working on a mixed-reality WiFi scanner that turns the Quest 3 into a spatial site-survey tool. Walk through a building and it maps signal strength directly into the room around you — while building a reusable floor plan at the same time.

Some of the features so far:

- Live 3D point clouds and per-floor WiFi heatmaps
- Multi-AP scanning with separate maps and estimated AP positions per BSSID
- Draw rooms, doors and windows directly in mixed reality
- Place notes, distance measurements, ping nodes and local throughput tests in physical space
- Browser dashboard with a live map, AP/floor filters and before/after scan comparison
- Export floor plans, heatmaps, CSV/JSON data, 3D geometry and a self-contained HTML report
- Everything runs locally on the Quest — no cloud and no separate receiver app required

The idea is to make WiFi troubleshooting feel less like staring at numbers and more like seeing the network painted onto the building itself.
